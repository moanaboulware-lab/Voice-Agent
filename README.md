# Voice-Agent
Please see attached screenshot of the Weatherford College Application Voice Agent.
1. Branch Design Challenge: What was the most challenging part of designing the conversation branches? Did you discover anything about how voice agents handle different conversation paths?
Answer: The hardest part was thinking of the right content to use to create the voice agent. Something that was simple enough, but had enough content to be able to ask questions and have valid answers that were credible. For my example, it handled each conversation seemlessly.
2. Knowledge Base Impact: How did the knowledge base content you added affect the agent's responses? Did certain types of content work better than others?
Answer: I added all my content in the beginning, so when I ran the test it had all content that it needed and answered the questions correctly without issue. Yes, when I tried to use websites, it had a read error on almost all of them. So I had to create word documents that had the information in it vice using URL. 
3. Real-World Application: What real-world application could this voice agent have? Think about a specific industry, business, or use case where this type of agent would be valuable.
Answer: This voice agent, if you add more content, could be used for the college to assist new applicants with the process of applying and getting access to financial aid and scholarships. It would be a good tool for college and universities to adopt.
